## [intro]
이 가이드는 MermanDraw로 첫 다이어그램을 만드는 방법을 안내합니다. 2분이면 충분하고 브라우저 하나만 있으면 됩니다.
**(screen ▶ 타이틀 카드)**

## [plan]
할 일은 네 가지입니다. 코드를 쓰고 테마를 고른 뒤 그림을 내보내고 링크를 보냅니다.
**(screen ▶ 단계 목록. 동사마다 한 줄씩 켜짐)**

## [write]
mermandraw.com에서 편집기를 엽니다. 코드는 왼쪽에 씁니다. 한 줄이 화살표 하나이고 대괄호 안의 글자가 상자 이름이 됩니다. 오른쪽 미리보기는 입력하는 동안 바로 다시 그려집니다. 여기서는 판단 상자에서 아니요를 고르면 처음으로 돌아갑니다.
**(screen ▶ write.webp: 코드 창 강조 / 코드 여섯 줄 돋보기 / 둘째 줄 오른쪽에 상자 이름 말풍선 / 미리보기 / 판단 상자)**

## [theme]
다음으로 Theme 메뉴를 엽니다. 테마는 Clean부터 Mono까지 7가지입니다. Neon을 고르면 미리보기가 바로 바뀝니다. 코드는 한 글자도 바뀌지 않습니다.
**(screen ▶ 커서가 Theme 클릭 / theme-menu.webp로 바뀜 / 메뉴 돋보기 / Neon 클릭 / neon.webp로 바뀜 / 코드 창 강조)**

## [export]
마음에 들면 그림으로 내보냅니다. SVG는 크기를 키워도 깨지지 않아 문서와 발표 자료에 잘 맞습니다. PNG는 이미지를 넣을 수 있는 곳이면 어디든 쓸 수 있습니다.
**(screen ▶ SVG와 PNG 돋보기 / 커서가 PNG 클릭)**

## [link]
보낼 때는 Link를 누릅니다. 복사된 주소에 다이어그램이 통째로 들어 있습니다. 따로 저장되지 않고 계정도 필요 없습니다. 다른 방법으로 Share가 있습니다. 메신저에서 미리보기 이미지가 뜨는 공개 페이지를 만듭니다.
**(screen ▶ 커서가 Link 클릭 / link.webp의 복사 알림 돋보기 / Share 버튼 돋보기. 공유 페이지 화면은 넣지 않음)**

## [end]
여기까지가 한 바퀴입니다. 쓰고 고르고 내보내고 보내면 끝입니다. 지금 mermandraw.com에서 해 보세요.
**(screen ▶ 마무리 카드)**
