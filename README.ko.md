# script-to-guide

**말하는 가이드.** 대본과 스크린샷을 넣으면 내레이션이 붙은 제품 사용 가이드가 나옵니다. 결과물은 2MB HTML이고, 파일이 필요하면 MP4로도 냅니다.

[Claude Code](https://claude.com/claude-code) / [Codex](https://openai.com/codex) 스킬입니다. MIT.

> **상태: 출시 전.** 사내 가이드 8편과 유튜브 시리즈를 만든 비공개 파이프라인에서 엔진을 떼어내는 중입니다. 아직 설치할 수 있는 것이 없습니다. 진행 상황은 영문 README의 [Roadmap](README.md#roadmap)에 있습니다.

## 무엇을 하나

대본을 씁니다. 문단마다 어느 장면인지, 화면에 무엇이 보여야 하는지 적습니다. 에이전트가 실제 앱을 헤드리스 브라우저로 캡처하고(캡처가 안 되는 화면은 그려서), 내레이션을 합성하고, 가이드를 조립합니다. 화면의 모든 동작은 내레이션의 단어에 걸립니다.

## 왜 영상 파일이 아닌가

제품 UI는 바뀝니다. 녹화한 영상은 그때 죽습니다. 대본에서 만든 가이드는 살아 있습니다.

- **키프레임 대신 큐.** 타임라인에 손으로 놓는 것이 없습니다. `cue(장면, 단어)`가 모든 강조, 확대, 커서 이동을 내레이션에 묶습니다. 문장을 바꾸고 다시 합성하면 화면이 따라옵니다.
- **재촬영 대신 캡처 한 장 교체.** 버튼 자리가 바뀌면 그 캡처만 바꾸고 다시 빌드합니다.
- **HTML입니다.** 글자가 선택되고 검색됩니다. 배속과 장 이동이 기본입니다. 따라하기 모드는 단계마다 멈춰서 보는 사람이 자기 앱에서 해 볼 수 있게 합니다. 문서나 헬프센터에 태그 하나로 끼웁니다.
- **필요하면 영상으로.** 같은 타임라인을 헤드리스 브라우저에서 프레임 단위로 찍어 MP4로 냅니다. 영상 프레임워크 의존성이 없습니다.
- **검산한 내레이션.** 합성한 음성을 다시 받아써서 대본과 비교합니다. 제품 이름을 잘못 읽으면 누가 듣기 전에 잡힙니다.

## 한국어에 대해

한국어로 8편을 만들며 쌓인 것이 들어 있습니다. 화면 표기와 낭독 표기를 분리하는 발음 치환 사전, 어절 단위 자막 시각 계산, 합니다체 내레이션 문체 규칙, 쓰인 글자만 담는 한글 폰트 서브셋. 영어 README가 정본이고, 이 문서는 요약입니다.
